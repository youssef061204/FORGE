# Learned traffic controller

An actual offline Double DQN learns two bounded signal choices from six observed directional queue/wait/phase/timer features. The 6 → 12 ReLU → 2 network trains on 156,672 transitions from 136 complete exploration episodes, with a target network, discounted rewards, gradient clipping and frozen 3,000 updates. Training ran on the RTX 5050 with PyTorch CUDA. Validation TD loss is diagnostic, not evidence of control improvement.

Deployment embeds the real learned weights into an ordinary strict TypeScript program. The host limits switch eligibility and eight proposals; a generated program still executes in the isolated worker and broker. Fixed signals, pressure, analytical uniform-budget optimization, DQN, learned-priority hybrid and explicitly labeled fixture source run on 24 paired scenes. Actual Bedrock sources are compared separately on the same seeds in bedrock-control.json. DQN trains at 10-second steps while deployment currently invokes every 40 seconds; this mismatch is disclosed.

The RL improvement over fixed is small; its paired 95% bootstrap interval includes zero. Never claim statistically demonstrated superiority. Five bounded responder/grid/shelter rule agents and central/decentral coordination have their own real broker evaluation in multi-agent.json; these agents are not independently learned. A trained Ridge model predicts actual +60-second local emergency demand from ten observed features and guides exact enumeration of three responder sites among twelve graph sites. Random, demand, optimization and learned placement execute on 24 paired City scenes with common tactical dispatch. resource-placement.json retains response-time differences, intervals and failures; mobile generators and shelter supply movement are unsupported.


Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. Paid calls are an explicit separate command; never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes. Whole episodes are the unit of splitting and inference evaluation. Git metadata is unavailable in this workspace.
