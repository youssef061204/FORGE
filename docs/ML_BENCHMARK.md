# Reproducible FORGE benchmark

Create .venv-ml with Python 3.11. Install scripts/ml/requirements.txt, then scripts/ml/requirements-gpu.txt for pinned PyTorch 2.10/cu128 on supported NVIDIA hardware, or scripts/ml/requirements-cpu.txt for CPU execution. PyTorch is required for the full suite; CUDA is optional. CPU-only runs must report GPU_UNAVAILABLE and retain CPU measurements. Set OMP_NUM_THREADS=2, OPENBLAS_NUM_THREADS=2 and MKL_NUM_THREADS=2. Run npm run benchmark:forge. It executes data collection, measured baselines/models, controller data/DQN, perception/fusion, actual CPU/CUDA field work, allocation, MILP, Z3, adversarial search, active learning, synthesis preflights, external/map import, ONNX parity, statistics and evidence export in sequence. npm run benchmark:ml is the smaller forecast/risk/allocation path. --only=stage,stage runs named stages for diagnosis; results are not mislabeled as a complete run.

Whole-scenario split manifests are fixed before fitting. Validation selects models and calibration. Held-out, shift and compositional partitions are never used for model selection. Failures and positive event counts are retained. Regression and controller comparisons use whole-episode bootstrap intervals. Adaptive testing saves observed unsafe runs after at least five, conservative dominated runs after ten, requires at least twenty safe runs for eligibility and expands to forty for OOD/close outcomes. Current agreement with exhaustive testing is 83.3% across only six paired cases; no universal winner-preservation claim is valid.

Model lifecycle retains hashes and training/validation/shadow evidence. A queue-only adapted model uses 32 fresh shift training episodes, eight validation and sixteen untouched new test episodes. Candidate held-out queue MAE 0.8165 versus base 0.8534. Promotion and rollback require owner API actions and never change capability grants. Closed-loop residuals are measured only after a previously predicted +60 second outcome exists; a configured review threshold does not trigger automatic retraining.

ONNX exports the real DQN and checks CPU inference parity/latency at batches 1/64/1024. TensorRT and custom CUDA kernels were not implemented or claimed. Vectorized PyTorch was the justified measured GPU optimization.


Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. Paid calls are an explicit separate command; never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes.
