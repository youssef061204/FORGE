# Current architecture

Home accepts an ordinary request. The owner API and MCP server discover typed connected resources, retrieve approved programs, and select reuse, extension, composition, synthesis or a missing connection. New source passes schema validation, strict TypeScript compilation, sandbox tests and read-only Reality Replay before exact owner approval. Installation makes a persistent tool discoverable through MCP. Invocation runs isolated software that proposes structured operations; the trusted broker checks current grants, bindings and input/output schemas before any effect.

Home, Tools, Activity and Inspect form the main product. Tools retain versions, status, source hashes, permissions and run history. Activity emphasizes committed connector receipts and explicit failures. Local polling, schedules and owner-authenticated event relay use persisted plans, duplicate suppression and an uncertain-write outbox; this is a bounded single-host backend, not a remotely subscribed webhook service or distributed scheduler. Imported software never inherits grants.
