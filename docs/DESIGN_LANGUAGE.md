# Design language

Primary navigation is Home, Tools, Activity and Inspect. Home begins with one ordinary request and shows a useful result or a specific missing resource. Tools show what remains installed and whether it is ready, paused or needs attention. Activity shows what actually changed, based on committed receipts. Inspect holds source, tests, exact access, provider metadata, connector setup and benchmark evidence.

The normal flow is request -> build -> test -> review -> approve -> run -> inspect the result. Review shows proposed effects and minimum access before an explicit approval. Progress and errors use short verbs and concrete facts. Development or replay output is labeled beside the result. Failed inference or missing connections cannot appear as successful live work. Local Ollama inference and file primitives are being implemented; copy must not claim verified local generation before its end-to-end proof succeeds.

The Twin is a secondary technical proving ground, reached deliberately rather than opening as the main product. Its overview canvas supports pan, zoom and asset selection. It has no walking avatar or WASD instructions. Traffic, hazards, forecasts and camera overlays describe synthetic conditions; imported real geometry is labeled separately. Legacy World/Studio/Lab fixtures remain secondary regression and technical facilities.

Use restrained color, generous spacing, readable text, visible focus, clear button names and progressive disclosure. Outcome receipts take precedence over cards of technical metadata. Keep credentials out of rendered pages. Canvas controls respect focused text inputs, and listeners and timers clean up on unmount. Verify the main flow at 1440 x 900 and narrow mobile widths; historical screenshots do not prove the current design.

Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. The current owner instruction prohibits paid features. Reproducing these documents reads local artifacts only; do not run paid verification or live cloud requests. Historical cloud artifacts remain evidence of earlier authorized work, never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes. Whole episodes are the unit of splitting and inference evaluation. Git metadata is unavailable in this workspace.
