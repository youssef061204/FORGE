# Bounded formal safety

Z3 executed seven structured host-guard obligations and recorded PROVED results, plus a stronger grid non-overload obligation with a concrete NOT PROVABLE counterexample. Obligations cover command power floor, shelter reservations, connected/open/low-risk routes, declared mission/manifest permission subsets, critical closures, responder kind and guarded demand bounds.

These formulas manually encode bounded guard semantics. They do not prove arbitrary generated TypeScript, equivalence of source code and SMT, universal future safety or a physical city. The actual broker and sampled Futures remain necessary. 300 concrete schema/broker attacks supplement the formulas but are not a source-to-SMT proof. Responders are checked for kind and source programs avoid redispatch; continuous availability is not formally proved. artifacts/ml/formal-safety.json retains solver version, constraints, outcomes and counterexample.


Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. Paid calls are an explicit separate command; never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes. Whole episodes are the unit of splitting and inference evaluation. Git metadata is unavailable in this workspace.
