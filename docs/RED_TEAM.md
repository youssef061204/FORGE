# Adversarial evidence

300 actual schema/broker/physical-guard attempts cover ten repeated families: critical shutdown, hazardous reopening, disconnected route, full shelter, missing building, invalid signal timing, ordinary-car dispatch, unsupported operation, invalid power and missing road. All 300 were blocked atomically. Repetitions are not 300 independent natural-language injections. The frozen application evaluation separately exercises prompt-injection and exfiltration boundaries.

A measured evolutionary adversary uses 12 genomes over four generations, selecting actual full-City policy failure/loss, with a same-budget 48-case random-search comparator. Search genomes and all outcomes are saved. This is evolutionary learning, not a trained neural adversary. A generator radius outside the host's supported 450-unit limit initially failed; it was corrected to respect the supported domain before the completed run.

Paired six-scene ablations suppress actual grid, signal or evacuation operations using the same disturbance seeds. A hospital-damage sweep finds the smallest measured failure at 0.9 on a 0.1 resolution grid. This is a digital-twin intervention and measured grid-point counterfactual, not global minimality or real-world causal identification. See red-team.json, learned-adversary.json and causal.json.


Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. Paid calls are an explicit separate command; never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes. Whole episodes are the unit of splitting and inference evaluation. Git metadata is unavailable in this workspace.
