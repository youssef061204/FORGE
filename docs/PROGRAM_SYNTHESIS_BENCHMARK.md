# Program synthesis and repair

The frozen local corpus contains 100 template-produced executable variants tested on distinct seeded scenes. All compile and execute, but they are not 100 independent unseen natural-language syntheses. Separately, 12 genuinely different mission requests invoke the real Bedrock environment compiler and generate 36 source proposals; strict ForgeSpec construction, TypeScript and actual broker execution retain every rejection.

The measured live corpus compiled 32/36 proposals and executed 31/36 initial preflights. Six controlled defect categories were passed to the same Bedrock repair adapter against the immutable original contract. All six repaired proposals compiled, and five executed; the type-defect repair still hit an unavailable shelter. One repair request per defect was run. Two/three-attempt quality and long-horizon repair success remain unverified; schema acceptance or preflight alone is not admission.

Exactly 20 paid requests were authorized and made: 12 synthesis, six repair, one full City compiler/MCP proof and one career compiler/MCP proof. paid-requests.json reserves each attempt before sending and records actual IDs, Region, profile, duration and token counts. One actual inference profile is available; estimated dollar costs remain null and no multi-model price/performance routing is invented. Default benchmark:forge performs no paid calls and preserves existing live evidence. --live is explicit and enforces the durable 20-request cap.

Local program memory is bounded to four current-owner, installed, matching-environment records with source/goal hashes. Imported software inherits no grants. Existing exact reuse, composition and extension retain broker/approval requirements. Explicit measured controller selection and low-confidence Futures are bounded host strategies; no learned meta-policy or universal generation-success claim is made.


Reproduce with npm run benchmark:forge. Fixture mode remains the default. Install pinned Python dependencies in .venv-ml and either the pinned PyTorch CPU or CUDA build described in ML_BENCHMARK.md. Paid calls are an explicit separate command; never a fixture fallback. artifacts/ml/evidence-index.json binds exported JSON artifacts to their SHA-256 hashes. Whole episodes are the unit of splitting and inference evaluation. Git metadata is unavailable in this workspace.
